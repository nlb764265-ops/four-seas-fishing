# 四海釣遊記

目前版本 DEMO 0.11，支援繁體與簡體中文。直接開啟 `index.html` 即可離線遊玩；頂部「简 / 繁」切換語言，選擇儲存在這個瀏覽器。公開試玩：https://nlb764265-ops.github.io/four-seas-fishing/ （0.11 部署結果見本版驗證紀錄。）

選擇水域與魚餌後開始掛機，出售漁獲、繳交賞金或製作料理，再提升售價、釣竿與容量。現有 9 處釣點、86 種魚，本版新增墾丁沿岸、香港吐露港、六帶鰺與多鱗沙鮻；圖鑑捕獲後顯示介紹，繁體附生難字注音，簡體附漢語拼音，兩種字體均可搜尋已捕獲魚種。

換釣點依距離支付單程旅費，地圖按鈕顯示本次金額。售價升級立即套用箱內漁獲及賞金；料理加價保存在個別漁獲的基礎價。各地收益維持接近，持續擴充地圖不必建立更高階梯。

自動存檔之外有 10 個手動存檔位，並可匯出入 JSON。存檔格式 4 接受舊格式 1～3；語言選擇獨立於存檔。舊格式缺少每尾魚原始售價等級，轉換時以當時金額除以存檔目前倍率建立基礎價，保留該金額後隨後續升級變動。存檔格式維持 4；舊檔可匯入。包含新魚種或新釣點的存檔請使用 0.11 或後續版本。

每竿一份魚餌；滿箱或餌用完會停止，離線最多結算兩小時。進度儲存在瀏覽器；跨網站與裝置可使用轉移碼或匯出入存檔。程式與資料全數包含在版本資料夾中，不需連線載入語言資源。

跨設備轉移：開啟「存檔與說明」中的「跨設備存檔轉移」，在來源設備選「帶走進度」產生轉移碼，再於另一台設備選「領取進度」，輸入代碼並核對後確認還原。轉移碼需要連線，有效 24 小時，持有代碼的人可以領取該進度。還原會取代接收設備的自動存檔，原進度保留為轉移前備份，十個手動存檔位保留。轉移的是當下正在遊玩的進度；若要帶走手動存檔，先讀取該存檔。轉移不會持續同步兩台設備，離線釣魚沿用最多兩小時的結算規則。

本機驗證：`node tests/engine.test.cjs` 與 `node tests/transfer.test.cjs`、`node tests/batch2.test.cjs`。實際改動、存檔轉換及驗證記錄見 [開發改動紀錄.md](開發改動紀錄.md)，現實魚類與讀音依據見 [SOURCES.md](SOURCES.md)。本輪尚無作者定稿的玩家公告。
