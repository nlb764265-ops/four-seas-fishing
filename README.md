# 四海釣遊記

繁體中文純文字掛機釣魚遊戲，使用真實世界地理與水域魚種。唯一圖像為雙色像素世界地圖。

目前版本：DEMO 0.8。公開試玩：https://nlb764265-ops.github.io/four-seas-fishing/

## 玩法

選擇水域與魚餌後開始掛機。每竿消耗一份魚餌，可能釣到魚或水草。出售漁獲、繳交入侵種賞金，或用指定魚做料理，再提升漁獲售價、釣竿與漁獲箱。包含 7 處釣點、70 種魚，保留時段、天氣及魚種出沒條件。

所有釣點均無裝備等級門檻。每次換點按起訖概略距離支付單程旅費：20 元＋每 100 公里 5 元（向上取整），最高 150 元；重訪及回程同樣付費，原地不收費。全域漁獲售價可提升 10 次，每次增加基礎金額的 10%，由 100% 至 200%；新漁獲賞金一起提高。售價與賞金於拋竿時取得等級、捕獲時確定金額，箱內已有漁獲維持原價。各地魚池的長期平均收益差距縮小，新增釣點不必接在更高階。

同一尾魚只能出售、繳賞金或做菜一次。魚餌 2／5 元，漁獲箱滿或魚餌用完會停止，離線結算最多兩小時。支援舊存檔遷移；舊金錢、漁獲售價及賞金保留，售價等級從 100% 開始，舊解鎖費不另退款。

以下為歷史版本紀錄，現行數值以上述 0.8 說明為準。

0.3 金額單位統一為元；圖鑑和漁獲箱採條目選擇與詳情框，支援分類、搜尋及手機底部詳情。新增基隆沿岸（240 元永久解鎖），包含黑鯛、黃鰭鯛與花身雞魚。側欄常駐小地圖，點選後開啟大地圖選擇水域；目前位置以定位圖釘和文字標示。0.2 存檔可直接沿用，數值維持。

0.4 小地圖預設以目前水域為中心顯示最大縮放。圖鑑未捕獲的魚只顯示編號，捕獲後才解鎖名稱、介紹及紀錄；料理與賞金也隨對應魚種解鎖。日月潭 11 種、曾文水庫 13 種、基隆沿岸 6 種，跨水域重複魚種合併後共 21 種；並非各地完整物種名錄。

0.5 重新平衡經濟。魚價整體下修並依水域分級，綜合餌 2 元、魚肉餌 5 元，魚餌成為實際成本。釣竿升級 400／1,600／5,500／16,000 元，漁獲箱 300／1,200／4,000／12,000 元。入侵種賞金約為市價兩倍；料理費用提高，效果延長為 25～30 竿。模擬一般玩法：約 50 分鐘解鎖曾文水庫、3.5 小時解鎖基隆沿岸、5 小時左右升滿裝備。介面改版：深色側欄與旅費卡、頂部狀態列、每竿收益與滿箱時間預估、「下一個目標」進度、卡片式裝備／料理／賞金頁，地圖顯示解鎖條件。舊存檔直接沿用。

0.5 另新增 18 種魚（共 39 種：日月潭 15、曾文水庫 23、基隆沿岸 13），琵琶鼠列入賞金。圖鑑未捕獲魚種改為顯示獲得線索。釣魚進度改為浮標漂移動畫，地圖縮放以游標位置為中心，遊戲說明精簡為玩法概念。

0.6 參考《風留的小屋》加入存檔系統：自動存檔之外另有 10 個手動存檔位，可讀取、匯出、匯入，並可開始新遊戲（只取代自動存檔，手動存檔保留）。全遊戲內文字放大。移除水域行情倍率，魚價只看魚種與重量；不再顯示每竿與每分鐘收益。新增關渡（淡水河口）與龍洞岩岸兩個釣點，共 5 處水域、63 種魚，圖鑑新增河口魚分類，蟾鬍鯰列入賞金。

0.7 加入時段與天氣。遊戲中的一天為現實 60 分鐘（清晨、白天、黃昏、夜晚），各水域天氣每 20 分鐘變換（晴、陰、雨），季節依現實月份；天氣由時間推算，所有玩家同一時刻相同，離線結算也逐竿依當時環境計算。日本鰻鱺、鯰魚、黑帶棘鰭魚為夜晚限定；黃鱔、黑星笛鯛夜晚較常見，蟾鬍鯰雨天較常見，藍豬齒魚與雙帶烏尾冬夜晚不出現，烏魚 11～1 月較常見；各水域整天平均收益與 0.6 相差 5% 以內。釣魚紀錄加入開竿環境、時段與天氣轉換、關渡漲退潮，以及偶爾出現的心境描寫與當地小知識，紀錄上限由 18 則提高為 40 則。狀態列、目前水域、地圖與圖鑑線索顯示時段、天氣與出沒條件。修正微小魚種重量四捨五入為 0 公斤導致存檔無法讀取的問題，舊存檔載入時自動修復；圖鑑卡片在窄欄不再把名稱擠成直排。

0.7 另新增七股潟湖（6,000 元，釣竿 Lv.2、漁獲箱 Lv.2）與澎湖內海（22,000 元，釣竿 Lv.4、漁獲箱 Lv.3）兩處釣點，共 7 處水域、70 種魚。七股潟湖依台江國家公園所列優勢魚種，新增大鱗鮻、綠背鮻、日本海鰶；澎湖內海依大倉灣海草床調查與澎湖海域觀察紀錄，新增嘉鱲、黃錫鯛、點帶石斑、青嘴龍占。兩處各有專屬的時段、天氣與漲退潮描寫及當地小知識。

0.8 改用每次旅行付費與全域售價成長，移除水域裝備解鎖門檻，重新平衡魚價及賞金。存檔格式升為 3，仍接受格式 1、2；10 個手動存檔位及匯出入維持。實際改動及驗證範圍見 `開發改動紀錄.md`。

## 儲存

自動儲存在目前瀏覽器，另有 10 個手動存檔位；可匯出與匯入 JSON。支援 0.1 存檔遷移；跨網站及裝置須自行匯出入。離線最多結算兩小時，仍受容量和魚餌限制。沒有帳號系統或雲端存檔，玩家進度不會上傳 GitHub。

## 本機執行與驗證

直接開啟 index.html 即可遊玩，地圖資料也包含在檔案內。亦可使用任意靜態伺服器。無需安裝依賴，無後端或建置步驟。Node.js 可執行 `node tests/engine.test.cjs` 檢查遊戲狀態與結算。

GitHub Pages 使用 main 分支根目錄發布，`.nojekyll` 停用 Jekyll。
