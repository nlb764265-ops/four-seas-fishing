# 四海釣遊記

目前版本 DEMO 0.9，支援繁體與簡體中文。直接開啟 `index.html` 即可離線遊玩；頂部「简 / 繁」切換語言，選擇儲存在這個瀏覽器。公開試玩：https://nlb764265-ops.github.io/four-seas-fishing/

選擇水域與魚餌後開始掛機，出售漁獲、繳交賞金或製作料理，再提升售價、釣竿與容量。現有 7 處釣點、84 種魚；圖鑑捕獲後顯示介紹，繁體附生難字注音，簡體附漢語拼音，兩種字體均可搜尋已捕獲魚種。

換釣點依距離支付單程旅費，地圖按鈕顯示本次金額。售價升級立即套用箱內漁獲及賞金；料理加價保存在個別漁獲的基礎價。各地收益維持接近，持續擴充地圖不必建立更高階梯。

自動存檔之外有 10 個手動存檔位，並可匯出入 JSON。存檔格式 4 接受舊格式 1～3；語言選擇獨立於存檔。舊格式缺少每尾魚原始售價等級，轉換時以當時金額除以存檔目前倍率建立基礎價，保留該金額後隨後續升級變動。0.9 存檔請繼續使用 0.9 或後續版本。

每竿一份魚餌；滿箱或餌用完會停止，離線最多結算兩小時。進度只儲存在瀏覽器；跨網站與裝置請匯出入存檔。程式與資料全數包含在版本資料夾中，不需連線載入語言資源。

本機驗證：`node tests/engine.test.cjs`。實際改動、存檔轉換及驗證記錄見 [開發改動紀錄.md](開發改動紀錄.md)，現實魚類與讀音依據見 [SOURCES.md](SOURCES.md)。本輪尚無作者定稿的玩家公告。
