# 四海釣遊記

目前版本 DEMO 0.13，支援繁體與簡體中文。直接開啟 `index.html` 即可離線遊玩；頂部「简 / 繁」切換語言，選擇儲存在這個瀏覽器。公開試玩：https://nlb764265-ops.github.io/four-seas-fishing/ （0.12 已於 2026-10-22 發布並完成公開驗證，見開發改動紀錄。）

選擇水域與魚餌後開始掛機，出售漁獲、繳交賞金或製作料理，再提升售價、釣竿與容量。現有 11 處釣點、95 種魚，本版新增德國博登湖、格賴夫斯瓦爾德潟湖與九種魚。圖鑑捕獲後顯示介紹，魚名與俗名的生難字附讀音（繁體注音、簡體漢語拼音）。搜尋框可輸入已捕獲的魚名或水域名稱，輸入水域會列出該水域全部魚種，未捕獲者仍以編號顯示；「全部」分類可按淡水魚、河口魚、海水魚摺疊。釣魚頁顯示目前水域已釣到幾種，點一下即可在圖鑑查看。

換釣點依距離支付單程旅費，沒有上限，地圖按鈕顯示本次金額；前往德國等遠程行程旅費較高。售價升級立即套用箱內漁獲及賞金；料理加價保存在個別漁獲的基礎價。各地收益維持接近。

料理共 32 道。所有可食用的魚都能做煎魚，另有 31 道依現實菜式考據的地方料理，例如西湖醋魚、砂鍋魚頭、柳川鍋、法蘭肯炸鯉魚；捕獲任一種對應魚材後解鎖。料理頁分為全部、可製作、加快等待、提高售價、增加重量，並按臺灣、中國・港粵、日本、東南亞、歐洲分組，可搜尋料理或魚名。湯鍋燉煮加快等待，清蒸水煮增加重量，煎炸烤燻提高售價；名菜效果較強、持續較久。圖鑑與漁獲箱標示魚種可食用或不可食用。圖鑑另列當地語言名稱：德國魚種附德語名，臺灣水域魚種附台語、客語四縣腔名稱（依教育部辭典），香港水域附粵語名稱（目前僅黃腳鱲）。

魚餌在釣到魚時才消耗 1 份，釣到水草、中途收竿或換釣點都不消耗；開始拋竿時需持有至少 1 份所選魚餌。滿箱或餌用完會停止，離線最多結算兩小時。

自動存檔之外有 10 個手動存檔位，並可匯出入 JSON。存檔格式 5 接受舊格式 1～4；格式 4 以前的存檔若正在拋竿，匯入時退回該竿已預扣的 1 份魚餌，之後依新規則在釣到魚時扣除。語言選擇獨立於存檔。包含新魚種、新釣點或格式 5 的存檔請使用 0.12 或後續版本；0.13 沿用格式 5，0.12 存檔可直接讀取，進行中的料理效果保留。

跨設備轉移：開啟「存檔與說明」中的「跨設備存檔轉移」，在來源設備選「帶走進度」產生轉移碼，再於另一台設備選「領取進度」，輸入代碼並核對後確認還原。轉移碼需要連線，有效 24 小時，持有代碼的人可以領取該進度。還原會取代接收設備的自動存檔，原進度保留為轉移前備份，十個手動存檔位保留。轉移的是當下正在遊玩的進度；若要帶走手動存檔，先讀取該存檔。

本機驗證：`node tests/engine.test.cjs`、`node tests/batch2.test.cjs`、`node tests/batch6.test.cjs`、`node tests/transfer.test.cjs` 、`node tests/cooking.test.cjs` 與 `node tests/names.test.cjs`。實際改動、存檔轉換及驗證記錄見 [開發改動紀錄.md](開發改動紀錄.md)，現實魚類與讀音依據見 [SOURCES.md](SOURCES.md)。本輪尚無作者定稿的玩家公告。
