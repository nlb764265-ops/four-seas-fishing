# 四海釣遊記

繁體中文純文字掛機釣魚遊戲，使用真實世界地理與水域魚種。唯一圖像為雙色像素世界地圖。

目前版本：DEMO 0.2。公開試玩：https://nlb764265-ops.github.io/four-seas-fishing/

## 玩法

選擇水域與魚餌後開始掛機。魚餌每竿消耗一份，可能釣到魚或水草。出售漁獲、繳交入侵種賞金，或用指定魚類做料理，再升級釣竿與漁獲箱。日月潭起始開放；曾文水庫以遊戲旅費永久解鎖，之後免費往返。

本版包含八種有分布依據的魚、魚類圖鑑、魚虎與珍珠石斑賞金、五道料理、兩種付費魚餌及五級裝備。水草為占用容量的雜物，不列入魚類圖鑑。賞金、出售及料理都會消耗魚體，同一尾魚不能重複使用。

## 儲存

自動儲存在目前瀏覽器，可匯出與匯入 JSON。支援 0.1 存檔遷移；跨網站及裝置須自行匯出入。離線最多結算兩小時，仍受容量和魚餌限制。沒有帳號系統或雲端存檔，玩家進度不會上傳 GitHub。

## 本機執行與驗證

直接開啟 index.html 即可遊玩，地圖資料也包含在檔案內。亦可使用任意靜態伺服器。無需安裝依賴，無後端或建置步驟。Node.js 可執行 `node tests/engine.test.cjs` 檢查遊戲狀態與結算。

GitHub Pages 使用 main 分支根目錄發布，`.nojekyll` 停用 Jekyll。

## 資料

詳見 [SOURCES.md](SOURCES.md)。魚類介紹依來源重寫，釣獲機率、重量、價格、賞金及料理效果屬遊戲設定。地圖採 Natural Earth 公共領域海岸資料。水域標記不代表實地釣魚位置許可。

未設定原創遊戲程式與文字的再授權條款；地圖原始資料維持其公共領域性質。
