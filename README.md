# 四海釣遊記

繁體中文純文字掛機釣魚遊戲，使用真實世界地理與水域魚種。唯一圖像為雙色像素世界地圖。

目前版本：DEMO 0.6。公開試玩：https://nlb764265-ops.github.io/four-seas-fishing/

## 玩法

選擇水域與魚餌後開始掛機。魚餌每竿消耗一份，可能釣到魚或水草。出售漁獲、繳交入侵種賞金，或用指定魚類做料理，再升級釣竿與漁獲箱。日月潭起始開放；曾文水庫（釣竿 Lv.2＋3,000 元）與基隆沿岸（釣竿 Lv.4、漁獲箱 Lv.2＋15,000 元）以遊戲旅費永久解鎖，之後免費往返。

本版包含三十九種有分布依據的魚、魚類圖鑑、魚虎、珍珠石斑與琵琶鼠賞金、五道料理、兩種付費魚餌及五級裝備。水草為占用容量的雜物，不列入魚類圖鑑。賞金、出售及料理都會消耗魚體，同一尾魚不能重複使用。

0.3 金額單位統一為元；圖鑑和漁獲箱採條目選擇與詳情框，支援分類、搜尋及手機底部詳情。新增基隆沿岸（240 元永久解鎖），包含黑鯛、黃鰭鯛與花身雞魚。側欄常駐小地圖，點選後開啟大地圖選擇水域；目前位置以定位圖釘和文字標示。0.2 存檔可直接沿用，數值維持。

0.4 小地圖預設以目前水域為中心顯示最大縮放。圖鑑未捕獲的魚只顯示編號，捕獲後才解鎖名稱、介紹及紀錄；料理與賞金也隨對應魚種解鎖。日月潭 11 種、曾文水庫 13 種、基隆沿岸 6 種，跨水域重複魚種合併後共 21 種；並非各地完整物種名錄。

0.5 重新平衡經濟。魚價整體下修並依水域分級，綜合餌 2 元、魚肉餌 5 元，魚餌成為實際成本。釣竿升級 400／1,600／5,500／16,000 元，漁獲箱 300／1,200／4,000／12,000 元。入侵種賞金約為市價兩倍；料理費用提高，效果延長為 25～30 竿。模擬一般玩法：約 50 分鐘解鎖曾文水庫、3.5 小時解鎖基隆沿岸、5 小時左右升滿裝備。介面改版：深色側欄與旅費卡、頂部狀態列、每竿收益與滿箱時間預估、「下一個目標」進度、卡片式裝備／料理／賞金頁，地圖顯示解鎖條件。舊存檔直接沿用。

0.5 另新增 18 種魚（共 39 種：日月潭 15、曾文水庫 23、基隆沿岸 13），琵琶鼠列入賞金。圖鑑未捕獲魚種改為顯示獲得線索。釣魚進度改為浮標漂移動畫，地圖縮放以游標位置為中心，遊戲說明精簡為玩法概念。

0.6 參考《風留的小屋》加入存檔系統：自動存檔之外另有 10 個手動存檔位，可讀取、匯出、匯入，並可開始新遊戲（只取代自動存檔，手動存檔保留）。全遊戲內文字放大。移除水域行情倍率，魚價只看魚種與重量；不再顯示每竿與每分鐘收益。新增關渡（淡水河口）與龍洞岩岸兩個釣點，共 5 處水域、63 種魚，圖鑑新增河口魚分類，蟾鬍鯰列入賞金。

## 儲存

自動儲存在目前瀏覽器，另有 10 個手動存檔位；可匯出與匯入 JSON。支援 0.1 存檔遷移；跨網站及裝置須自行匯出入。離線最多結算兩小時，仍受容量和魚餌限制。沒有帳號系統或雲端存檔，玩家進度不會上傳 GitHub。

## 本機執行與驗證

直接開啟 index.html 即可遊玩，地圖資料也包含在檔案內。亦可使用任意靜態伺服器。無需安裝依賴，無後端或建置步驟。Node.js 可執行 `node tests/engine.test.cjs` 檢查遊戲狀態與結算。

GitHub Pages 使用 main 分支根目錄發布，`.nojekyll` 停用 Jekyll。
